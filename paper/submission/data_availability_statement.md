# Data Availability Statement

This study uses only publicly available, de-identified benchmark data; no original patient data
were collected. All experiments are simulation-based: MedMNIST specialty subsets stand in for
individual hospitals under a cross-specialty non-IID partition.

The datasets analyzed are part of **MedMNIST v2** [Yang et al., 2023, *Scientific Data*,
https://doi.org/10.1038/s41597-022-01721-8] and are publicly available at
https://medmnist.com/ and https://doi.org/10.5281/zenodo.6496656. Five specialty subsets were
used: PathMNIST, DermaMNIST, BloodMNIST, OCTMNIST, and TissueMNIST.

Licensing: DermaMNIST is distributed under CC BY-NC 4.0; PathMNIST, BloodMNIST, OCTMNIST, and
TissueMNIST are distributed under CC BY 4.0. Users should consult the MedMNIST project page for
the current license terms of each constituent source dataset before redistribution.

No new data were generated in this study.
